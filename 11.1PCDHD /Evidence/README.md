
# Project Evidence

This folder contains photographs and screenshots
documenting the implementation and testing of the
Two-Bed IV Monitoring System.

## Evidence Categories

- Complete hardware assembly
- Arduino and sensor connections
- Load cell calibration
- Optical drop detection
- OLED display and buzzer alerts
- Bluetooth communication
- Raspberry Pi integration
- Web monitoring dashboard
- Mobile dashboard
- Headless operation

The project is a water-only academic demonstration
prototype and is not intended for clinical use.
